Integrasi Situs Multipage

1. Deskripsi

Praktikum ini bertujuan menggabungkan beberapa halaman website dengan navigasi dan tampilan yang konsisten.

2. Halaman Website

- "index.html" — Halaman beranda.
- "kegiatan.html" — Halaman kegiatan.
- "daftar.html" — Halaman pendaftaran.
- "css/style.css" — Mengatur tampilan website.

3. Cara Menjalankan

Buka folder proyek di VS Code, lalu jalankan "index.html" menggunakan Live Server.

4. Pengujian

Pengujian dilakukan dengan memeriksa navigasi, link, CSS, gambar, dan tampilan website pada berbagai ukuran layar.

5. Hasil

Website diharapkan memiliki halaman yang saling terhubung, tampilan yang konsisten, dan dapat diakses dengan baik.

6. AI Use Statement

AI digunakan untuk membantu memahami materi dan memperbaiki kode. Saran yang diberikan perlu diuji kembali melalui browser.
