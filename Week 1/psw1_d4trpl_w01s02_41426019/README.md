Debugging adalah proses menemukan, menacari dan memperbaiki (eror/bug) code pada program supaya aplikasi yang di gunakan berjalan lancar. Siklus kerja dari Debugging adalah mereka bakal membaca laporan kesalah untuk memahami gejala anomali yang terjadi. Setelah itu progremer mencari sumber atau penyebab dari eror tersebbut dengan memeriksa code dan melakukan pengujian. Setelah didapatkan kesalahan progremer akan memperbaiki code tersebut dan menguji kembali untuk melihat hasilnya apakah masih eror atau tidak.
